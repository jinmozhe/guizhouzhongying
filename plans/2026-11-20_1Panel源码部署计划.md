# 1Panel 源码部署计划

## 当前状态和结果

- 状态：已结束
- 结果：已完成；本地部署入口、Admin 反代配置和运行手册已交付，生产尚未部署

## 关联需求

`BASE-GEN-002`、`BASE-GEN-004`、`BASE-MP-003`、`BASE-OPS-003`。

## 背景

贵州众赢独占目标服务器。现有生产入口从镜像仓库拉取包含 Backend 源码的镜像。目标环境由 1Panel 管理，支持将宿主机源码目录挂载到 Python 容器。

## 目标

提供单一 1Panel Python 运行环境的本地部署文件。通过锁定的 Python 解释器和依赖运行宿主机源码，由 OpenResty 托管 Admin 静态产物和对外入口。

## 非目标

上线、执行真实数据库迁移、构建 Admin 生产产物和触发远程工作流。

## 现状分析

`compose.prod.yml` 用应用镜像提供 Backend、日志消费者和 Admin。Admin 的 Nginx 上游依赖 Compose 服务名 `backend`。Backend 应用本身从工作目录读取 `.env`，支持独立运行 Alembic 和权限同步。

## 方案设计

为 1Panel 管理的 Python 服务提供部署模板，固定基础镜像 digest，挂载已验证 Commit 对应的只读源码、生产配置和持久目录。发布准备与启动分别执行，运维命令复用同一套虚拟环境。Admin 同域保留原有 API 与媒体路由。

## 全栈影响矩阵

| 范围 | 是否涉及 | 工作内容 | 前置依赖 | 验证 |

2. 增加启动脚本、部署模板和 OpenResty 接线。
3. 同步生产规则、手册和发布追溯边界，运行适用检查。
