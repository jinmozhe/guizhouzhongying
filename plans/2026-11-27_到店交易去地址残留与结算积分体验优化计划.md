# 到店交易去地址残留与结算积分体验优化计划

## 1. 当前状态和结果

- 当前状态：已结束
- 结束结果：已完成；小程序收货地址入口与历史物流残留清理、结算页自动首次报价与一键积分重算、管理端到店订单详情修正与平台运费菜单隐藏及文档更新均已完成，Miniapp 与 Admin 轻量门禁和仓库治理检查通过；重型自动化测试与动态视觉验收未执行

## 2. 关联需求

- `BASE-LOCAL-004`：SKU 上限内积分与现金组合购买
- `BASE-LOCAL-005`：商家核销及七天未用整单退款
- `BASE-MP-001`：C 端唯一形态为微信小程序
- `BASE-ADMIN-005`：交易履约与售后工作台

## 3. 背景

当前项目已确立“微信小程序线上购买、线下商家整单核销、无收货地址、无运费”的实际运营形态，后端下单服务已对到店订单强制拒绝 `address_id` 并固定零运费。但在前端仍残留早期物流电商入口与文案：小程序“我的”页面仍露出“收货地址”菜单并注册地址页面，订单筛选保留“待发货 / 待收货”，订单详情与售后页面仍展示“运费 ¥0.00”与物流退款文案，管理后台侧边栏仍展示“平台运费”且到店订单详情误显示“虚拟订单无地址”。同时，小程序结算页进入后不会自动拉取报价，点击“使用本单最大积分”后会清空报价并要求用户二次点击“获取最新报价”。

## 4. 目标

1. 清理小程序“收货地址”菜单入口、分包路由与回跳白名单，移除与当前纯到店业务冲突的物流筛选、零运费展示及过时协议/隐私/帮助文案。
2. 优化小程序结算页交互：进入页面自动拉取服务端报价，一键使用最大积分或取消积分抵扣后自动重新报价，减少重复点击并保持服务端报价指纹、防并发乱序与会话隔离约束。
3. 修正管理端到店订单详情的“收货快照”误导文案，在管理端菜单隐藏“平台运费”入口，同时保留后端接口、数据库表与历史物流订单数据兼容。

## 5. 非目标

1. 不删除后端 `/addresses` 接口、地址表、运费表或修改 OpenAPI 契约与数据库结构，保留历史订单权益与向后兼容。
2. 不修改后端积分计价算法、冻结/扣减/退款账本逻辑及核销码生成流程。
3. 不执行未获本次授权的重型验证（production build、Vitest、pytest、Playwright、微信编译与真机动态验收）。

## 7. 方案设计

1. **适用规则与落点核对**：
   - 小程序配色规则（`docs/design/miniapp/color-standard.md`）：结算页一键积分按钮继续复用现有 `.reward-button` 语义样式（金柑橙底 + 墨蓝字），主操作保持深钴蓝，价格保持价格红，错误提示通过 `QueryState` 给出原因与重试入口，不引入新色值。
   - 小程序架构与防错边界（`apps/miniapp/AGENTS.md`）：结算自动报价通过递增序号 `quoteSeq` 与 `session.epoch === sessionScope()` 防乱序和串号；只读报价可自动触发，创建订单仍须用户主动点击并弹窗确认，未知结果保留原 `request_id` 与恢复入口。
   - 管理端边界（`apps/admin/AGENTS.md`）：路由隐藏使用 Umi 配置项 `hideInMenu: true`，保留 `access.ts` 与既有权限测试不破坏。
2. **小程序清理与优化**：
   - 移除 `entries.ts` 中的“收货地址”项、`app.config.ts` 中的 `addresses/index` 路由及 `auth-target.ts` 中的地址回跳白名单。
   - 精简 `OrdersPage.tsx` 订单筛选为 `全部 / 待付款 / 待核销 / 已完成 / 已付款 / 已取消`；到店单隐藏零运费行，保留历史订单地址快照兼容。
   - `AftersalesPage.tsx` 按 `fulfillment_mode === 'local'` 区分到店单与历史单的弹窗、退款明细与提示文案，明确展示积分返还与现金退回。
   - 同步修正 `LegalSheet.tsx`、`privacy-sections.ts` 与 `HelpPage.tsx` 中的收货地址与配送过时表述。
   - `CheckoutPage.tsx` 改为进入页自动首次报价，并提供“使用本单最大积分 / 取消积分抵扣”一键触发并自动重算报价。
3. **管理端清理**：
   - `apps/admin/config/routes.ts` 为 `/catalog/shipping` 增加 `hideInMenu: true`。
   - `apps/admin/src/features/trade/OrdersPage.tsx` 对 `fulfillment_mode === "local"` 展示“到店整单核销（无收货地址）”及成交总额、积分抵扣与现金应付明细，保留非到店历史订单的收货快照展示。

## 11. 风险与回滚

- **风险**：结算页自动报价若未处理异步乱序，可能导致旧报价覆盖新积分输入；若页面重复 `useDidShow` 触发无条件报价，可能打断用户手动输入。
- **控制措施**：使用单调递增序号过滤过期响应，仅在未提交草稿首次进入当前 `request_id` 时自动报价，手改积分后清空报价指纹并由用户点报价或一键切换按钮显式触发。
- **回滚**：本次不涉及数据库、契约或后端接口变更，直接回退前端对应文件即可完全恢复。
