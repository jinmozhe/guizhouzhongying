# 微信手机号绑定超时修复计划

## 1. 状态与授权

- 状态为已结束。
- 结果为已完成本地修改和轻量验证，真实绑定未验收。
- 用户授权修复微信手机号绑定故障，调用上限为 15 秒。
- 关联需求为 `BASE-BE-002`、`BASE-MP-001`、`BASE-QUAL-001`。

## 2. 范围与实施

本地手机号绑定请求约 2.1 秒返回 `PHONE_BINDING_UNKNOWN`，无凭据探测复现 2 秒连接超时。按 Backend 工程标准复用共享客户端，应用凭据获取和手机号换码共用 15 秒预算，连接上限 10 秒。按可观测性规范记录阶段、脱敏原因和请求关联信息。

按小程序工程标准通过现有传输层设置手机号绑定请求 20 秒等待时间。凭据获取阶段失败与明确拒绝允许重新授权。手机号绑定结果未确认时读本人状态，重新授权使用新 code。手机号 code 仍由服务端一次性消费。

范围覆盖 Backend、Miniapp 和运维文档。Admin、Web、API Client、Database 与 Deployment 无实施项。回滚时按文件撤销本次超时、脱敏日志和页面状态差异。

## 3. 验证

- Backend Ruff、格式、Mypy、导入边界、内存编译、应用导入与 OpenAPI 逐字节核对通过。
- Miniapp typecheck 和 lint、工作区和模块边界检查通过。内存模拟核对两个阶段的超时响应、请求次数和一次性 code 标记。
- pytest、Vitest、微信编译与真实绑定未执行。
